# M0 工程基座 — 实现设计

- **版本**：2.0
- **状态**：已实现（验收用例：`tests/integration/test_m0_acceptance.py`）
- **依据**：[路线图](./roadmap.md) §4、[设计文档](../design.md)（D7、§9.1、§10）

**目标**：后续所有里程碑都在「可恢复、可观测」的地基上开发，而不是先写业务再补基建。

**演示口径**：启动一个空流程 job → 中途 kill 进程 → 重启 → 从 checkpoint 续跑；日志自动关联 `trace_id` / `span_id`。

**为何不可延期**（设计 D7）：研究任务耗时 5–30 分钟，M1 起的验证回路调试离不开断点续跑。后补 checkpointer 的典型风险是图状态已积累不可序列化对象。

## 2. 工程基座锁定项

这些选择在 M0 拍板，后续里程碑不得另起炉灶：

| 维 | 值 |
|----|-----|
| Python | ≥ 3.13；包管理 **uv**；锁文件入库 |
| 布局 | `src/prospector/` 单包 |
| 格式 / 类型 / 测试 | ruff（format + lint）、basedpyright、pytest |
| 迁移 | Alembic |
| DB schema | 业务 `app`；checkpointer `langgraph` |
| 领域合同 | Pydantic v2 |
| 主键 / 哈希 / 时间 | UUID；SHA-256；UTC → ISO-8601 |

**依赖方向**（全程硬约束）：`config` ← `store` / `obs` ← `flow` ← `runtime/entrypoints`。`flow/` 永不导入 `runtime/`。

## 3. 主战役：空流程与 Checkpoint

图状态必须**可序列化**（D7）：禁止放入未注册的自定义类实例、打开的连接、线程锁、协程对象。

M0 的图不是业务图，而是 **checkpoint 探针**：`step_a → step_b → step_c`，每个节点递增 `step`、append `notes`、打一条含 `job_id` 的 structlog INFO 并创建短 OTel span。`step_b` 用文件屏障控制可杀窗口，便于集成测试在窗口内 kill。

恢复语义（验收期望）：

1. 创建 `jobs` 行（`status=running`），以该 job 的 `thread_id` 调用图；
2. 进程在 `step_b` 执行中被强制终止；
3. 新进程用同一 `thread_id` 恢复，已完成的 `step_a` **不重跑**，从中断点继续到 `end`；
4. 最终 `notes` 完整、`status=completed`，checkpoint 行存在于 `langgraph` schema。

`store/checkpoint.py` 职责单一：构造固定 `search_path=langgraph,public` 的同步 psycopg 连接池，暴露 `get_checkpointer()` / `setup_checkpointer()` 与连接池生命周期，不含业务节点逻辑。

**观测的故障隔离**：OTel exporter 失败不得阻断 checkpoint 提交或进程正常退出。日志内容最小化——默认禁止密钥、连接串与研究正文。

## 5. 交接面

| M0 留下的接口 | 被谁接走 |
|---------------|----------|
| `flow/research_graph.py` + 可序列化 `state` | M1 换成真研究图；状态字段扩展但保持可序列化纪律 |
| `store/checkpoint.py` | 全程复用；M4 恢复 in-flight 仍靠它 |
| `store/object_store.py` | M1 Document 快照；M2 树产物；M3/M4 debug `payload_ref` |
| `obs/` | M1 root / agent / 工具 span；M4 跨进程 link |
| `app.jobs` | M1+ 扩展列与邻表 |
| compose PG + MinIO | M4 再加 Redis / RabbitMQ / 观测后端 |

**已落地的实现选择**：checkpointer 用同步 `PostgresSaver`；对象存储客户端用 `boto3`；kill/resume 集成测试用文件屏障控制可杀窗口；根目录不保留 `main.py`，入口由 `pyproject.toml` 指向 `runtime.entrypoints.local`。
